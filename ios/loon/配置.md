# Loon 配置

简体中文 | [English](configuration.en.md)

[返回插件列表](README.md)

使用 **Loon 3.5.1（983）或更新版本**；当前插件采用新版 Script 配置语法。

1. 在 Loon「配置 → 插件」中添加列表里的下载地址，启用插件。
2. 在配置中开启 MitM，生成并安装证书。在 iOS「设置 → 通用 → VPN 与设备管理」中安装描述文件，再到「设置 → 通用 → 关于本机 → 证书信任设置」中，对刚安装的根证书开启完全信任。
3. 开启复写与脚本功能，确认插件中的复写规则、JavaScript 脚本和 MitM 域名已加载。
4. 启用客户端连接，使目标 App 的流量经过当前配置。确认脚本已下载且没有报错，修改配置后完全退出并重新打开目标 App。

旧订阅应替换为列表中的新地址，并停用处理相同请求的旧插件。

参考：[Loon 插件文档](https://nsloon.app/docs/Plugin/)、[iOS 证书信任说明](https://support.apple.com/zh-cn/102390)。
