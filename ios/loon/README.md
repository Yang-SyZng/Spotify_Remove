# 配置

在已安装对应 App 的 iPhone/iPad 上点击“一键导入”；若未唤起 App，可复制下载地址手动添加。

确保开启 MitM、复写和 JavaScript 脚本功能，安装并信任 MitM 证书，启用插件并确认脚本下载完成。
