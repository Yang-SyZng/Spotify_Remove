# Shadowrocket 配置

简体中文 | [English](configuration.en.md)

[返回插件列表](README.md)

1. 在 Shadowrocket「配置 → 模块」中添加列表里的下载地址，启用模块，并确认当前使用的配置已加载该模块。
2. 在当前配置的 HTTPS 解密（MitM）设置中开启解密，生成并安装证书。在 iOS「设置 → 通用 → VPN 与设备管理」中安装描述文件，再到「设置 → 通用 → 关于本机 → 证书信任设置」中，对刚安装的根证书开启完全信任。
3. 确认当前配置允许重写，模块中的 JavaScript 脚本已启用，所需域名已包含在 HTTPS 解密列表中。
4. 启用客户端连接，使目标 App 的流量经过当前配置。确认脚本已下载且没有报错，修改配置后完全退出并重新打开目标 App。

旧订阅应替换为列表中的新地址，并停用处理相同请求的旧模块。

历史 Spotify 安装教程及配图：[归档教程](archive/spotify-NoAD.md)。

参考：[Shadowrocket 功能介绍](https://apps.apple.com/app/shadowrocket/id932747118)、[iOS 证书信任说明](https://support.apple.com/zh-cn/102390)。
