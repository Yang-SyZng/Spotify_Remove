# Quantumult X 配置

简体中文 | [English](configuration.en.md)

[返回插件列表](README.md)

1. 将列表里的下载地址添加到重写资源，启用该资源并更新内容。
2. 开启重写和 MitM，在 MitM 设置中生成并安装证书。在 iOS「设置 → 通用 → VPN 与设备管理」中安装描述文件，再到「设置 → 通用 → 关于本机 → 证书信任设置」中，对刚安装的根证书开启完全信任。
3. 确认资源中的 MitM 域名已加载，JavaScript 脚本已下载。脚本规则随重写资源生效。
4. 启用客户端连接，使目标 App 的流量经过当前配置。确认脚本已下载且没有报错，修改配置后完全退出并重新打开目标 App。

旧订阅应替换为列表中的新地址，并停用处理相同请求的旧重写资源。

参考：[Quantumult X 配置示例](https://github.com/crossutility/Quantumult-X/blob/master/sample.conf)、[iOS 证书信任说明](https://support.apple.com/zh-cn/102390)。
