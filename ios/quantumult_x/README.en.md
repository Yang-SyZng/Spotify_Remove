# Configuration

On an iPhone or iPad with Quantumult X installed, tap “Import into Quantumult X”.

Enable MitM and rewrites, install and trust the MitM certificate, enable the rewrite resource, and confirm that the JavaScript file has downloaded.

Instructions: [Configuration](configuration.en.md).
